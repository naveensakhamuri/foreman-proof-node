## What

Make `sum(numbers)` throw a `TypeError` when given something that is not an array, or an array containing a value that is not a finite number.

## Done when

`npm test` passes, including tests that `sum("1,2")`, `sum([1, "2"])` and `sum([1, NaN])` throw TypeError, and `sum([1, 2])` is still 3.
